# 컨베이어 위의 침팬지 (Chimp Conveyor)

브라우저 안에서 돌아가는 소형 LLM 한 마리를 "침팬지 직원"으로 복사해 쓰는 프롬프트 릴레이 퍼즐. 도트 스타일 생산 라인, 작업지시 12개, 각 작업은 전표 10장 배치. 라인은 한 마리로 시작해 네 마리까지 길어진다.

## 의도

적당히 멍청한 일꾼들에게 지시하는 답답함 속에서 조금씩 흘러나오는 정답의 쾌감, 그리고 어처구니없는 실수로부터의 웃음. 공장 경영 시뮬레이션이 아니다. 침팬지는 끝까지 적당히 멍청해야 하고, 진행은 플레이어의 손을 조금 편하게 해 줄 뿐이다.

## 세계관

사장은 라인 노동자를 전부 잘랐다. 대신 들여온 건 아주 작은 침팬지 한 마리를 복사한 일꾼들. 플레이어는 유일하게 남은 사람으로, 침팬지마다 지시서 한 장을 쓴다. 침팬지는 무급이다(악덕업주). 원재료만 녹는다.

## 핵심 루프

- 작업지시 하나 = **샘플 전표 3장**(입력 → 기대 출력)을 보여 주고, 가동하면 **전표 10장**이 라인을 통과한다. 10장 안에는 예외(필드 순서 변경, 추가 필드, 두 자리 수, 대소문자 혼용, 단수형, 약어, 처음 보는 도시)가 섞여 있다. 샘플에 과적합한 지시는 예외에서 죽는다.
- 침팬지 k는 **k−1의 출력만** 받는다. 플레이어는 침팬지마다 자유 형식 영어 지시를 쓴다(글자 제한).
- 전표 하나가 라인을 다 지나면 최종 출력을 채점(`match`, `itemThreshold`)해 ✓/✗. **10장 중 6장 이상 ✓면 합격**, 다음 작업 해금.
- 가동마다 원재료 값이 나가고(실패해도), 정답 전표 1장마다 납품가/10을 받는다. 2장만 맞아도 본전.
- 현금이 원재료 값보다 적으면 은행 대출 ₩5,000 버튼. 부채는 결산에 나온다.
- 지시서에 배치의 정답 문자열을 그대로 적으면 사장이 가로챈다. 원재료는 소모되지 않는다.
- 12개 작업을 모두 통과하면 연간 결산과 판정 한 줄.

## 진행(자동)

통과한 작업 수 = 현장 숙련도 레벨. 레벨마다 세 값이 자동으로 오른다. 상점도, 등급도, 사고 모드도 없다.

| Lv | 마리 | 지시서 글자 | temperature | 출력 토큰 |
|---|---|---|---|---|
| 0~2 | 1 | 60 / 65 / 70 | 0.35 / 0.34 / 0.33 | 48 |
| 3~6 | 2 | 80 / 90 / 100 / 110 | 0.31 / 0.30 / 0.28 / 0.27 | 56 / 56 / 64 / 64 |
| 7~9 | 3 | 120 / 130 / 140 | 0.25 / 0.24 / 0.22 | 72 / 80 / 88 |
| 10~11 | 4 | 150 / 160 | 0.21 / 0.20 | 96 |

temperature 0.6은 대문자화 같은 쉬운 작업에서도 부품 코드를 망가뜨려(3~5/10) 시작값을 0.35로 낮췼다. "작업 기억"(원본 전표를 참고로 붙이기)은 측정에서 침팬지가 참고 쪽 첫 줄을 베끼게 만들어 진행에서 뺐다(`memoryLevel: 0`).

## 경제 (`economy.js`)

시작 현금 ₩3,000. 대출 ₩5,000/회, 이자 없음. 원재료 = 납품가/5.

결산 판정(순이익 = 현금 − 부채 − 3,000): ≥ 30,000 사장 자화자찬 / ≥ 0 "혁신" 사보 / ≥ −30,000 침팬지 탓 / 그 밑 은행이 공장 인수.

예외 수는 1 → 5로 늘고 못된 항목은 레벨당 1개(광주 코드, 하이픈 2개 코드, 영어 숫자 단어, 첫 필드). 각 작업의 `batch[i].note`에 예외 사유, `trap`에 순진한 시도가 어떻게 망하는지 적혀 있다. 결과 표에서 ✗ 행에 마우스를 올리면 채점 상세가 보인다.

### 밸런스 근거 (Qwen2.5-0.5B 측정)

- **안정**: 대문자화(재차 대문자화는 코드를 망가뜨림), 콜론 필드 값(첫 필드 제외; `key=value`는 "=A3"), JSON 필드 값(item/dest), 질문형 숫자(두 자리·단수·약어·숫자 둘도 OK), 콜론 접두어(숫자·단어에만; 하이픈 코드는 "M8"로 쪼갬), 변환 예시 있는 괄호(`B7 becomes [B7]`; 입력과 닮은 예시는 베낌), 지시서 안 도시 코드표(광주·소문자 도시 실패), 문장→JSON, 긴 출력 복사(짧은 라벨 복사는 라벨을 떼어냄).
- **불가(함정 전용)**: 줄 필터, "N번째 줄", `job 3:` 줄 고르기(라벨을 되뱉음), 세기, 산술, 비교, 번역, 글자 치환, 두 단어 필드값, 부품 코드 대응표(40~60%), **모델이 모르는 임의 대응표**(도시→도크 번호 D1~D4는 0/10; 공항 코드는 모델이 반쯤 알아서 됨), JSON 배열 값에서 item 꺼내기(수량을 냄), 숫자 라벨(`PALLETS: 8`)에 괄호 치기(라벨을 뗌), `qty: 400 pcs`가 있는 전표에서 팔레트 수 묻기(pcs를 냄), 모호한 지시, 한국어 지시.
- 특정 단어는 대문자화조차 못 한다: bolt→BUDDY/BUTTON, washer→WATERPLANE, belt→BEAM. 레벨 1 부품명은 이 단어들을 피해 골랐다.
- 예시에 정답과 같은 문자열을 쓰면 옛 정답 가로채기 장치에 걸렸고, 배치 10장에서는 정답 하드코딩이 1/10밖에 못 맞히므로 그 장치는 제거했다.
- Qwen3 thinking을 켜면 비교·세기·산술이 100% 통과해 실수가 사라진다. 그래서 사고 모드는 넣지 않았다.

## 채점 (`similarity.js`)

| match | 방식 |
|---|---|
| `exact` | 정규화(펜스/따옴표 제거, 공백 축약, 괄호 안 공백 제거, 끝 문장부호 제거) 후 동일. 대소문자만 다르면 0.9 |
| `fuzzy` | Levenshtein 유사도와 토큰 Jaccard 중 큰 값 |
| `set` | 쉼표/줄바꿈으로 나눠 집합 Jaccard |
| `number` | 첫 숫자 파싱. 군말이 붙으면 0.9 |
| `json` | 펜스 제거 후 parse, leaf 값 일치 비율. 한 원소 배열은 스칼라로, 대소문자 무시, 불필요한 키 ×0.9 |

등급: 10/10 전량 합격 / ≥6 합격 / ≥3 아깝다 / 그 외 대참사. 별: 합격 + 지시서 예산 60% 이하 3개, 합격 2개, 3장 이상 1개.

## 비주얼

- 폰트: 한국어 도트 폰트 Galmuri(11/14/Mono11, jsDelivr), 영문 숫자 Press Start 2P(Google Fonts). 모서리 없음, 2px 테두리, 4px 오프셋 그림자, 검정 배경에 노랑 강조.
- `scene.js`: 카드 행 위의 픽셀 캔버스(내부 72px 높이, CSS 3배). 벨트, 스테이션마다 침팬지, 이동하는 소포, 입고/출하 상자 카운터. 가동 중에만 rAF.
- `sprites.js`: 16×16 문자열 배열 스프라이트(idle/think/write/happy/sad/dead, 소포, 상자, 벨트). `drawSprite()` 한 함수 뒤에 있어 PNG 스프라이트 시트로 교체 가능.

## 기술

- 순수 HTML/JS/CSS, 빌드 없음. GitHub Pages 정적 배포.
- LLM: WebLLM 0.2.85(jsDelivr ESM), 모델 `Qwen2.5-0.5B-Instruct-q4f16_1-MLC` 고정. **WebGPU 필수**(데스크톱 Chrome/Edge). 첫 실행 시 수백 MB 다운로드 후 브라우저 캐시.
- system 프롬프트(한/영): 공장 침팬지 직원, 결과만 출력. user: 지시 → `Input:` → `Output:`.
- `postClean`이 펜스와 "Sure! Here is…" 접두를 제거. **날것 모드**를 켜면 정리 없이 전달.
- 한 판 소요: 1마리 10장 ≈ 10초, 4마리 10장 ≈ 40초(애니 생략 시).

## 작업지시 추가

`WORK_ORDERS`에 객체를 추가하고 `PROGRESSION`에 한 줄을 더한다. 샘플 3장은 배치의 앞 3장과 같은 유형으로, 예외는 "더 일반적인 지시"로 살아남을 수 있는 것 위주로, 못된 항목은 1장만. 추가 후 예시 지시서로 3회 이상 실제 가동해 6~9/10인지 확인한다. 10/10이 계속 나오면 예외를 더 넣고, 5/10 이하면 완화한다. `id`는 저장 키이므로 바꾸지 않는다.
